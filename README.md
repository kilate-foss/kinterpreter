# Kilate
- An easy interpreted programming language.

## Syntax
```
work Main(): Int {
        String hello_message = "Hello, world"
        Print -> hello_message
        return -> 0
}
```

## How to install Kilate

### 🐧 Linux

> Requirements: ruby, cmake, make, C++ compiler (g++ or clang)

### 1. Clone the repository

```bash
git clone https://codeberg.org/trindadedev/Kilate
cd kilate
```

### 3. Install

```
ruby make.rb --install
```

## How to use Kilate
Below we have the basic interpreter commands.

## Run
```bash
kilate run <files>
```

## Help
```bash
kilate help
```
